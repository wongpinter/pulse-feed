# Pulse Feed

A fast, privacy-focused multiplatform feed reader supporting RSS 2.0, Atom 1.0, JSON Feed v1.1, and OPML across Android, Desktop, and iOS.

> **Attribution:** Pulse Feed is an open-source fork based on **[Harmonic](https://github.com/SimonHalvdansson/Harmonic-HN)**, originally designed and created by **Simon Halvdansson** (Apache License 2.0). We retain Harmonic's Kotlin Multiplatform foundation, Material 3 UI polish, reader mode, ad blocker, and local AI capabilities.

---

## Features

- **Universal Feeds**: Subscribe directly to RSS 2.0, Atom, JSON Feed v1.1, or auto-discover feeds from any website URL.
- **Full Card Grid & List Modes**: Adaptive Material 3 full card grid with lead image heroes and topic-matched editorial gradient placeholders, plus compact list mode.
- **Folders & Smart Categorization**: Organize subscriptions into custom folders and filter streams with automatic topic chips (`AI`, `Programming`, `Security`, `Science`, `Business`, `Design`, `Hardware`, `Privacy`).
- **In-App Reader & Full Webpage View**: Switch seamlessly between distraction-free Reader Mode (with local AI summarization) and an embedded in-app browser without leaving the app.
- **OPML Import / Export**: Migrate subscriptions from any feed reader via standard OPML 2.0.
- **Privacy & FOSS Hygiene**: Local encrypted storage, zero tracking, built-in ad host blocklist, and strict offline-first persistence.
